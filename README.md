# Нічліг

Планувальник автоподорожі: вказуєте, звідки й куди їдете, а застосунок прокладає швидкий маршрут трасами, ділить дорогу на дні й підбирає готель на кожну ніч.

Стан: робоча версія в розробці. Вхід користувачів і зберігання даних на сервері ще не зроблені (див. «Обмеження»).

## Запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
npm run dev        # режим розробки, адреса з'явиться в терміналі
npm run build      # перевірка типів і збірка в dist/
npm run preview    # перегляд зібраної версії
npm test           # юніт-тести
```

Ключі й змінні середовища не потрібні: усі зовнішні сервіси, які використовує застосунок, відкриті.

## Що вміє

- Маршрут авто між двома точками, найшвидший, з часткою шляху великими дорогами.
- Поділ дороги на дні за часом за кермом (ліміт задає користувач).
- Готелі біля кінця кожного дня: ціна, відстань від траси, гак у хвилинах, сортування.
- Сторінка готелю зі знімками місця з повітря і розбором ціни.
- Збереження поїздок, демонстраційне бронювання, підписка (імітація без оплати).
- Дві верстки, телефон і десктоп. На широкому екрані їх перемикає кнопка збоку.

## Як це працює

1. **Маршрут.** OSRM повертає геометрію і час по кожному відрізку. Частку великих доріг рахуємо за номерами трас (E, М, Н, A, S, DK).
2. **Контрольні точки.** Ідемо вздовж маршруту за часом. Остання година перед денним лімітом це вікно ночівлі.
3. **Готелі.** Шукаємо в радіусі 10 км від ділянок, де може випасти ночівля. Для України й Польщі готелі лежать у `public/data/hotels.json` (вивантаження з OpenStreetMap), для інших країн іде живий запит до Overpass.
4. **Вибір.** Готелі оцінюються за гаком, ціною, зірками. Наступний день починається від вибраного готелю. Якщо у вікні готелів нема, день стає коротшим, але ніколи не довшим за ліміт.

Уся ця логіка лежить у `src/lib` і не залежить від інтерфейсу.

## Структура

```
src/lib/          ядро: маршрут, контрольні точки, планувальник, ціни, джерела даних
src/lib/__tests__ юніт-тести
src/pages/        сторінки
src/components/   карта, картки, іконки
src/data/         приклад плану для головної (зібраний з реальних даних)
public/data/      готелі України й Польщі
scripts/          вивантаження готелів, прогін сценарію в Chrome
```

## Тести

`npm test` запускає 69 юніт-тестів. Вони покривають те, де помилка найдорожча:

- розбиття на дні: жоден день не довший за ліміт, останній доходить до фінішу, поведінка без готелів;
- оцінка й сортування готелів, фільтр бюджету;
- модель цін і її розбір на складники;
- розбір відповідей OSRM та Overpass з відсіюванням непридатних і підозрілих даних.

Зовнішні сервіси в тестах не викликаються. Окремий живий прогін: `LIVE=1 npm test`.

Сценарій у справжньому браузері (потрібен Google Chrome і запущений `npm run preview -- --port 4199`):

```bash
node scripts/walkthrough.mjs http://localhost:4199/ docs/screens 1440 900
```

## Обмеження

- **Ціни демонстраційні.** Їх рахує модель (тип закладу, зірки, сезон, день тижня). Справжні ціни готелів доступні лише за партнерськими договорами.
- **Бронювання й підписка імітовані**, оплати нема.
- **Дані користувача зберігаються в браузері** (localStorage). Входу і захисту даних на сервері ще нема.
- **Знімки з повітря показують місце, а не сам готель:** фото готелів у OpenStreetMap нема.
- **Публічні сервери** OSRM, Overpass і плиток карти мають ліміти й можуть відповідати повільно.
- Час у дорозі без заторів. Гак до готелю оцінюється за відстанню до траси.
